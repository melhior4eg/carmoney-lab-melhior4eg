# Агенты Kilo: что кому можно

- **code** — может всё в рамках своих прав: править файлы, запускать команды, коммитить и проверять результат тестами и линтером.
- **ask** — только анализирует: читает файлы и отвечает на вопросы, ничего не меняет; для реализации предлагает переключиться на code.
- **plan** — проектирует до кода: собирает требования и пишет пошаговый план, ждёт подтверждения; сам код не правит.
- **debug** — лечит баги методично: читает код и логи, воспроизводит проблему, добавляет диагностику и исправляет причину.

На практике из этой сессии: раздел «Как проверить, что сервис жив» в ask я мог только подготовить как текст, а в code — сразу записать в README.
